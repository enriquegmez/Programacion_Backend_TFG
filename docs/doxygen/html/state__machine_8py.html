Detailed Description

La máquina de estados del Protocolo (FSM).

Implementa el patrón Máquina de Estados Finitos para garantizar que los comandos del protocolo R2Pilot se ejecuten en un orden seguro y en sincronía con el cliente. Evalúa las transiciones sin ejecutarlas (can_transition) y las consolida solo si hay éxito confirmado (commit_transition).
