Detailed Description

Máquina de estados del protocolo de comunicación R2Pilot.

Mantiene tres submáquinas paralelas (Global, Movimiento y Monitorización) para permitir operaciones concurrentes seguras (ej. teleoperar mientras se hace streaming de vídeo), evitando colisiones de comandos.
