Detailed Description

Administra el ciclo de vida de la conexión física de red (WebSockets) y la sesión lógica.

Garantiza que solo un operador tome el control del robot, valida la autenticidad de los comandos mediante un identificador único UUIDv4 y monitoriza el enlace físico mediante un bucle síncrono/asíncrono de Watchdog.
