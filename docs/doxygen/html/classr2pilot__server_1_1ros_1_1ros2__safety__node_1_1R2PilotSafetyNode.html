Detailed Description

Filtro de seguridad reactivo para teleoperación.

Escucha los comandos crudos generados por el joystick del usuario, evalúa el entorno del robot mediante los sensores láser suscritos dinámicamente, y publica velocidades seguras al controlador final del robot.
