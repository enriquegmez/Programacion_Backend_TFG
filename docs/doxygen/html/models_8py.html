Detailed Description

Representación interna del protocolo R2Pilot (Clases de Dominio).

Contiene la estructura de datos orientada a objetos (Dataclasses) del servidor. Está diseñado para coincidir 1:1 de forma estricta con las reglas de protocol_schema.json, garantizando la compatibilidad con el cliente móvil.
