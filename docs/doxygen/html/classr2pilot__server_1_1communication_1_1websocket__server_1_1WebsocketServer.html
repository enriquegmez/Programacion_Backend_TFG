Detailed Description

Servidor asíncrono basado en WebSockets.

Gestiona el ciclo de vida de los sockets físicos (Apertura, Recepción en bucle, Cierre) y actúa como puente inyector de dependencias (Callbacks de envío) para que las capas lógicas no dependan de librerías de red específicas.

Bucle principal de atención al cliente (Lanzado por cada nueva conexión).

Delega la validación de acceso al ConnectionManager, genera los callbacks de inyección y procesa en bucle infinito los paquetes entrantes hasta que el socket se destruye.
