Detailed Description

Administrador de los actuadores físicos del robot.

Se encarga de inyectar las velocidades en el cortafuegos de seguridad (SafetyFilter) y de enrutar las peticiones angulares a los controladores de hardware dinámicos descubiertos por el URDF.

Abre o cierra el semáforo lógico para permitir inyección de velocidades.

Controla el estado de la bandera is_control_active y valida que el tópico de destino exista y sea compatible con Twist o JointTrajectory según corresponda.

Parameters

Returns
