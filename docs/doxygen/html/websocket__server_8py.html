Detailed Description

El Servidor asíncrono de la comunicación con el cliente móvil basado en WebSockets.

Se encarga exclusivamente de levantar el puerto de escucha, mantener el bucle asíncrono de recepción, enviar los mensajes por la red mediante WebSockets y derivar el procesamiento lógico de los mensajes (deserialización) al Director central.
